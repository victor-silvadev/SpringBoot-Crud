# Meu Primeiro CRUD com Spring Boot 

Este repositório contém o meu **primeiro projeto utilizando Spring**, desenvolvido passo a passo enquanto acompanhava o excelente curso **"Spring Boot 3 | Complete Course 2023"** da **Michelli Brito**.

---

##  Sobre o Projeto
O objetivo deste projeto foi aprender e aplicar os conceitos fundamentais para a criação de uma API RESTfull robusta utilizando as tecnologias mais modernas do ecossistema Spring.

## Tecnologias Utilizadas
* **Java 21**
* **Spring Boot 4**
* **Spring Framework**
* **Spring Web**
* **Spring Data JPA**
* **Banco de Dados** (Postgres)
* **Maven**

---

## 📚 O que foi estudado e implementado
* **Configuração Inicial:** Geração do projeto via *Spring Initializar*.
* **API RESTfull:** Criação de endpoints estruturados seguindo boas práticas.
* **CRUD Completo:** Implementação das operações de Criação, Leitura, Atualização e Exclusão.
* **Modelo de Maturidade de Richardson:** Compreensão e aplicação dos níveis de maturidade para APIs REST.
